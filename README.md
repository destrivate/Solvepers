# Solvepers

> Solvepers — это открытый репозиторий для совместного творчества и разработки, у которого принципиально нет одного автора или владельца. Продукт создается и принадлежит абсолютно всем, кто вносит в него свой вклад.

Каждый вносит свою часть — текст, код, рисунок, перевод, идею — и всё вместе складывается в одно целое.

## Как это работает?

### 1. Идея

| Шаг | Действие |
|-----|----------|
| **Предложение** | Создаёшь Issue с описанием идеи |
| **Принятие** | Все адекватные идеи попадают в проект |
| **Перенос** | Принятые идеи уходят в `ideas/` и становятся частью проекта |

### 2. Разработка

| Шаг | Действие |
|-----|----------|
| **Находим** | Ищем задачу, которую можно взять |
| **Разрабатываем** | Пишем код, текст, переводы |
| **Pull Request** | Создаём PR, происходит проверка |
| **Продолжение** | Можно продолжить чужой код или доработать его |

### 3. Завершение

Когда идея **точно выполнена**:

1. Найди файл с тем же названием в `work/` и `ideas/`.
2. В обоих файлах поменяй статус на `Done`.
3. Создай PR с переносом файла в `release/`.

> ⚠️ Перенос в release осуществляется автором репозитория. 

## Что вы получите?

**Награда** ≠ власть. Поэтому будет отдельная доска с отдельными благодарнастями.

## Как начать?

1. Прочитай [rules.md](RULES.md)
2. Выбери идею из `ideas/` или предложи свою через Issue
3. Создай PR — и ты уже часть проекта
